Homebase isn't running

Nothing is answering on http://localhost:5757.

Start Homebase

  1. Start the Homebase Server task from PowerShell: Start-ScheduledTask -TaskName 'Homebase Server'
  2. Or open PowerShell in your Homebase folder and run: npm start
  3. Still not starting? This shows the task, the health check and the end of the logs: powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\status.ps1 -LogLines 40

Let new tabs start Homebase

Open PowerShell in your Homebase folder and run the installer once. It sets up the Homebase Server task and the launcher that Chrome and Edge use to start it: powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1

Then click Try starting again. Details: docs\setup\autostart.md in your Homebase folder. Until then, npm start in that folder starts Homebase by hand.

Install the launcher for this extension

The launcher only answers the extension ID it was installed for, and this extension's ID (unknown) isn't it — or its settings are missing. Run the installer again from your Homebase folder so it allows this ID: powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1

Then click Try starting again. Details: docs\setup\autostart.md in your Homebase folder.

Load the extension again (one time)

Since version 0.2.0 this extension has a fixed ID, nbaolbakegefnefgojdokagajincnfjj, and the launcher only answers that ID. Your browser still runs it under its old ID (unknown), which the installer can't change.

  1. Open chrome://extensions (or edge://extensions) and click Remove on Homebase New Tab.
  2. Click Load unpacked and select the extension folder in your Homebase folder.
  3. Using a port other than 5757? Set it again in the extension options (removing the extension clears it).
  4. If you haven't yet, install the launcher from your Homebase folder: powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1

Details: extension\README.md in your Homebase folder.
