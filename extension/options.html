New tab options

New tabs open whatever Portly on this PC is set up for: Portly itself.

New tabs open your Portly Pages site, the address below. It uses Portly on this PC when that is running and this browser is paired with it, and the copy kept in this browser otherwise. The site looks for Portly at the address it was built with (http://127.0.0.1:5757 unless PORTLY_STATIC_SERVER was set), not at the port below.

New tabs open Portly at http://localhost:5757 when it's running, and a simple fallback page with a search box when it isn't.

Where your Portly Pages site is published — the address the server trusts as PORTLY_PAGES_URL. Leave it empty to use the address Portly on this PC reports. It starts with https://; http:// only for a build served on this PC (localhost, 127.0.0.1 or [::1]).

Portly on this PC

Whichever page new tabs open, the extension uses this port to check whether Portly is running and to start it.

A whole number from 1024 to 65535 (default 5757). It must match the port the server uses (PORTLY_PORT).

Starting Portly

When Portly isn't running, the extension asks the Portly launcher to start it — when the browser starts and when you open a new tab. scripts\install-autostart.ps1 installs the launcher for this extension's ID only.
