# Review tags of October 2026 (UX-, PERF-, A11Y-)

The October 2026 review passes of the web app left numbered tags in code comments and test
names: `UX-<n>` for a usability finding, `PERF-<n>` for a performance finding, `A11Y-<n>` for an
accessibility finding. The tags stay where they are (a `grep -rn 'UX-[0-9]' web/src server/src`
lands on the code that answers each one; UX-1 is the one finding with tags on the server side);
this file is where they resolve. Each line says what the code or test next to the tag stands for,
in the code's own words, and where it lives. A number that several places share was one finding
with more than one consequence.

Paths are relative to the repository root. Tests are the files ending in `.test.ts` / `.test.tsx`.

## UX (usability)

- **UX-1** Short names instead of marketing text, and a reset warning that covers everything: a
  bookmark is named after the site ("GitHub", "BBC News"), not after the whole `<title>` string
  (the title split in `server/src/modules/bookmarks/html.ts`, its cases in
  `server/src/modules/bookmarks/favicons.test.ts`), with the site's name taken from its address
  ("Netflix" for netflix.com) as the fallback title until the page's own arrives (`siteName` in
  `web/src/widgets/launchpad/BookmarkDialog.tsx`, tagged in `siteName.test.ts` next to it); and a
  credential reset warns that the addresses of ICS subscriptions are deleted too, since feed
  addresses are vault secrets as well, and re-runs the ICS job right away
  (`web/src/test/settings/Accounts.test.tsx`, `server/src/modules/core/core.test.ts`).
- **UX-2** First-run defaults follow the browser's locale (week start, temperature, wind and
  precipitation units), applied only while the general settings are still exactly the schema
  defaults: `web/src/grid/localeDefaults.ts`, `localeDefaults.test.ts`,
  `web/src/grid/seed.test.tsx`.
- **UX-3** In the narrow stacked layout, the list widgets (launch pad, Todoist, mail, feeds,
  sports, and the calendar in its agenda view) size to their content; clock, search and weather
  keep their row height (weather for its layout tier): `web/src/widgets/registry.test.ts`,
  `web/src/grid/Grid.test.tsx`.
- **UX-4** At a widget's minimum size its empty and location states are one compact row with a
  single action (mail at 3x4, narrow and not only short; weather at 2x3):
  `web/src/widgets/mail/Widget.test.tsx`, `web/src/widgets/weather/weather.test.tsx`.
- **UX-5** General settings save as you go: choices right away, text fields when they lose focus,
  on Enter and when the section is left, with no Save button to forget:
  `web/src/settings/sections/General.tsx`, `web/src/test/settings/General.test.tsx`.
- **UX-6** Finding and handling tiles and widgets: a newly added widget is scrolled into view
  (clear of the edit toolbar) and glows briefly (`web/src/grid/Grid.tsx`, `Grid.module.css`,
  `Grid.test.tsx`); a launch pad tile has a menu (Edit, Move to, Delete) outside edit mode,
  opened by right-click, a long press, Shift+F10 / the context-menu key or its "..." button
  (`web/src/widgets/launchpad/Widget.tsx`, `Widget.test.tsx`); after a delete in edit mode the
  reflowing tiles ignore clicks for 400 ms (`DELETE_COOLDOWN_MS` in `EditBoard.tsx`,
  `Widget.test.tsx`).
- **UX-7** Clock: no "Good evening" at 2:15 AM (the night greeting is "Hello"), and extra time-zone
  chips that do not fit on the chip row become one "+N" chip naming them:
  `web/src/widgets/clock/Widget.tsx`, `clock.test.tsx`.
- **UX-8** The default layout fills its rectangle: no gaps, no overlaps, one straight bottom edge:
  `web/src/widgets/registry.test.ts`.
- **UX-9** Weather: a short but wide card (compact tier, 6 columns or more) shows a short hourly
  strip beside the current conditions instead of an empty middle:
  `web/src/widgets/weather/layout.ts` (`isWideCompact`), `weather.test.tsx`.
- **UX-10** A call to action lands where the work is: a widget's settings open in the field they
  are about (weather's "Set a location" goes straight to the city search; "Add an ICS feed" opens
  `#/settings/calendars?focus=ics` in the link field), and the edit toggle that cannot work in a
  narrow window says why on a tap and to screen readers ("Editing needs a wider window"):
  `web/src/grid/WidgetSettingsDialog.test.tsx`, `web/src/grid/Grid.test.tsx`,
  `web/src/widgets/calendar/CalendarsSettings.test.tsx`, `web/src/widgets/weather/weather.test.tsx`.
- **UX-11** Appearance: switching the background Image to Gradient and back brings the uploaded
  photo (and its blur and dim) back instead of an empty drop zone:
  `web/src/settings/sections/Appearance.tsx`, `web/src/test/settings/Appearance.test.tsx`.
- **UX-12** Search keys are discoverable and suggestions are never stale: the `?` help also lists
  the search box keys (`web/src/lib/hotkeys.ts`, `web/src/app/ShortcutsDialog.test.tsx`), the engine
  menu explains the keyword switch (`web/src/widgets/search/Widget.tsx`, `Widget.test.tsx`), and
  suggestions for text that was since deleted or replaced are not shown (`web/src/api/search.ts`,
  `web/src/widgets/search/Widget.tsx`, `Widget.test.tsx`).

## PERF (performance)

- **PERF-1** First paint and chunk split: a new tab paints last-known content in its first frame
  (the persisted cache is restored before the first render and the visible widgets' code is
  loaded, so neither an empty page nor the widgets' skeletons are committed when the data is
  cached: `web/src/app/boot.test.tsx`), and the launch pad's view board is its own chunk without
  @dnd-kit (the edit board and the dialogs load when the browser is idle or when first needed:
  `web/src/widgets/launchpad/Widget.tsx`, `EditBoard.tsx`, `tiles.tsx`, `Widget.test.tsx`).
- **PERF-2** A widget that knows from the persisted account list that there is nothing to load
  shows its connect state at once and never asks for data (mail with no mail account, Todoist not
  connected): `web/src/widgets/mail/Widget.test.tsx`, `web/src/widgets/todoist/Widget.test.tsx`.
- **PERF-3** Lookups are cached and batched: the locale-default answers are cached instead of
  refetched (`web/src/grid/seed.test.tsx`), and engine icons look each site up once, a few sites at
  a time (`web/src/widgets/search/engineIcons.test.tsx`).

## A11Y (accessibility)

- **A11Y-1** Color picker swatches are announced by name ("Red", "Orange", ...), with the hex code
  as their description: `web/src/ui/ui.test.tsx`.
