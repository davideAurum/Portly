# Tabs

Tabs that switch between panels in a dialog or settings card (Radix tabs: roles, panels and arrow keys).

Compose `Tabs` (with `defaultValue` or `value` and `onValueChange`), then `TabsList` with `aria-label`, one `TabsTrigger` per panel, and one `TabsContent` per panel. Give tabs short nouns as labels. Don't use tabs for navigating between pages.

Source: `web/src/ui/Tabs.tsx`.
