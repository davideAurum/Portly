# BrandMark

Beacon, the Portly lighthouse, as inline SVG: the simplified drawing below 48px and the full one from 48px.

It is decorative by default. Pass `label` when the mark alone names a control. Changing the `turn` number makes the light go round once (about 3 seconds). The header's home button does this on each press, and it stays still under reduced motion. `BrandLockup` adds the lowercase "portly" in the app font next to it. Don't recolour, stretch or outline the mark, and keep clear space of at least the tower's width around it.

Source: `web/src/ui/BrandMark.tsx`.
