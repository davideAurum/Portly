# Banner

An inline notice across the top of a page or card: info, success, warning or danger.

`title` is one short sentence. `children` adds detail and `actions` adds buttons on the right (they wrap below on narrow screens). Warning and danger banners are announced as alerts and the others as status. Each tone comes with its own icon, so colour is never the only signal. Say what happened and what to do next, for example: The local server is not running. Start it from the Portly tray icon, then reload.

Source: `web/src/ui/Banner.tsx`.
