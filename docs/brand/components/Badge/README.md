# Badge

A small pill for status, counts and labels.

Tones: `neutral` for plain facts (Read-only), `accent` for counts and highlights (3 unread), and `success`, `warning` and `danger` for states (Connected, Sign-in needed). Add `dot` for a status dot or `icon` for a lucide icon. The words carry the meaning, so colour is never the only signal. Keep the text to one to three words in sentence case.

Source: `web/src/ui/Badge.tsx`.
