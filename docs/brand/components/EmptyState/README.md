# EmptyState

What a widget or page shows when it has nothing to show: an icon or artwork, a title, an optional body and action.

Use `icon` (lucide) for widgets, and `media` (for example `BrandMark` at 64px) for the empty dashboard. Write the title as a plain fact ("Inbox zero", "Nothing today") and use the body for the next step. `compact` collapses to one row for very short widgets and hides the media.

Source: `web/src/ui/EmptyState.tsx`.
