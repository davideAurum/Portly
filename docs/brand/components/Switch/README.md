# Switch

An on/off setting that takes effect immediately, with the label on the left and the switch on the right.

Use it for settings that apply right away (Frosted glass, Show seconds). Use Checkbox instead for choices that are saved with a form or for list items. Give it `label` and, optionally, `description`. Inside a Field, the Field supplies the label. `size="sm"` is for dense lists.

Source: `web/src/ui/Toggles.tsx`.
