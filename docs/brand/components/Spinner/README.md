# Spinner

An indeterminate loading ring in `currentColor`.

Its sizes are 14, 16 (default) and 24. Give it `label` when it is the only thing saying that something is loading (it becomes `role="status"`). Omit the label inside busy buttons. For content that is loading, prefer skeletons; use a spinner for short waits and actions.

Source: `web/src/ui/Spinner.tsx`.
